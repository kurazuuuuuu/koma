# koma

Terraform の思想を、状態を持ち・順序に意味があり・実時間で動く系に適用し、エージェントが常時運用する前提に作り直した Minecraft サーバープラットフォーム。

**設計段階。実装なし。**

1. **可逆性を設計に入れる** — 戻せるものは自動、戻せないものだけ人間
2. **真実を1つにする** — state file を持たない
3. **判断を閉集合にする** — 発明させず、既存の手順から選ばせる

名前は駒（エージェント）・盤（掲示板）・定跡（手順）・棋譜（ログ）から。
