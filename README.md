# koma

> Terraform の思想を、状態を持ち・順序に意味があり・実時間で動く系に適用し、エージェントが常時運用する前提に作り直したもの。

AI エージェントが Minecraft サーバーの**開発から運用まで**を担うためのプラットフォーム。

**Status: 設計段階。実装なし。**

## 何を解くか

| 問題 | 帰結 |
|---|---|
| サーバー運用が属人的 | 再現できず、戻せない |
| エージェントに運用を渡す | 確認できない変更を高速に実行する |
| 監視はできる | 「なぜそうなったか」が残らない |
| 承認を増やす | ゲートが形骸化する |

解き方は3つ。

1. **可逆性を設計に入れる** — 戻せるものは自動、戻せないものだけ人間
2. **真実を1つにする** — state file を持たない。実状態を毎回読む
3. **判断を閉集合にする** — エージェントに発明させず、既存の手順から選ばせる

## 名前

```
駒   = ピース（エージェント）
独楽 = 回り続けて均衡を保つ（継続的な収束）
コマ = フレーム（離散的なリビジョン）
```

将棋の語彙がそのまま識別子になる（詳細は[用語集](docs/glossary.md)）。

| 将棋 | koma |
|---|---|
| 駒 | エージェント |
| 盤 | 掲示板（`koma now`） |
| **定跡** | **playbook**（レビュー済みの手順） |
| 棋譜 | イベントログ |
| 蔵 | 成果物ストア |
| 脳 | 学習した信念 |

比喩は**識別子にだけ**使う。本文の装飾には使わない。
