# 用語集

用語を固定する。以降の設計書・スキル・CLI はすべてこの語彙を使う。

## 将棋由来

| 語 | 読み | 意味 |
|---|---|---|
| 駒 | koma | エージェント。1つのタスクを実行する単位 |
| 盤 | ban | `koma now` が返す掲示板。誰がどこで何をしているか |
| 定跡 | joseki | playbook。事前に書かれ、レビューされた手順の DAG |
| 棋譜 | kifu | イベントログ。JSONL。追記のみ。任意時点を再生できる |
| 蔵 | kura | content-addressed な成果物ストア |
| 脳 | nou | 事実から導出された信念の索引。参照専用 |

## 予定のコマンド

| コマンド | 問い | 性質 |
|---|---|---|
| `koma describe` | システムは何であるか | 設定・リビジョン。全値に来歴 |
| `koma now` | システムは今なにをしているか | 生きた調整状態。自己失効する |
| `koma brain` | システムは何を学んだか | 履歴・教訓。再構築可能 |

## 状態

| 語 | 意味 |
|---|---|
| 事実 | 不変・権威。蔵 + 棋譜 |
| 信念 | 導出・版付き・参照専用。脳。統合ジョブだけが書く |
| リース | 資源の独占権。TTL 付き。ハートビートで更新 |
| 資源 | 排他の単位。サーバー、成果物ストアなど |
| ドリフト | 望ましい状態と実状態の差 |

## 配置

| 語 | 意味 |
|---|---|
| ノード | Minecraft サーバーを動かすホスト。全サーバーがどれか 1 つに所属する |
| gateway | プレイヤーの接続を受ける入口。ゲームサーバーのポートの代わりに公開する |

## 可逆性クラス

自律性の上限を決める。上から順に戻しやすい。

| クラス | 意味 | 例 |
|---|---|---|
| `config` | 再読込で戻せる | Paper 設定 |
| `policy` | テーブル差し替え | 認可規則 |
| `pointer-swap` | ポインタ交換 | プラグイン版、プレイヤーが遊ぶ前のワールド成果物 |
| `restart` | 再起動が要る | 外部プラグイン jar |
| `irreversible` | 戻せない | データ削除、権限剥奪の連鎖、プレイヤーが遊んだ後のワールドの巻き戻し |

戻すとプレイヤーの進行が消えるものは、手段がポインタ交換でも `irreversible` に分類する。実行時の状態でクラスが変わる操作は、最も戻しにくいクラスを宣言する。

人間のゲートを通るのは、`irreversible` の操作と、[自動化しない条件](design.md#サプライチェーン)に当たる更新。

## 保証レベル

| 段 | 手段 | 対象 |
|---|---|---|
| L0 | 静的解析 / 型 | 構文・依存方向 |
| L1 | 純関数 + property | ロジックの全域性 |
| L2 | MockBukkit | コマンド・権限の配線 |
| L3 | GameTest | ブロック・エンティティ挙動 |
| L4 | ボット E2E | プレイヤー視点 |
| L5 | 負荷・ファズ | 性能の相対劣化 |
| L6 | 本番観測 | 不具合の発生 |

L0 は検査の範囲内で保証する。L1 は標本による検査で、保証に近いが完全ではない。L2 以降は検出であって保証ではない。

## 使わない語

| 使わない | 理由 | 代わりに |
|---|---|---|
| 「適切に」「必要なら」 | エージェントが推測で埋める | 条件とコマンドを書く |
| `latest` | 挙動が静かに変わる | 版をピン留めする |
| 「デフォルト値」 | 省略が意味を持つ | 全域必須にする |
| 「テストで保証」 | L1 は標本検査で、L2 以降は検出である | 保証レベルを明示する |
