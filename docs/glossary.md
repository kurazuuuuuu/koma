# 用語集

用語を固定する。以降の設計書・スキル・CLI はすべてこの語彙を使う。

## 将棋由来

| 語 | 読み | 意味 |
|---|---|---|
| **駒** | koma | エージェント。1つのタスクを実行する単位 |
| **盤** | ban | `koma now` が返す掲示板。誰がどこで何をしているか |
| **手** | te | スキル呼び出し1回 |
| **定跡** | joseki | playbook。事前に書かれ、レビューされ、定石化された手順の DAG |
| **棋譜** | kifu | イベントログ。JSONL。追記のみ。任意時点を再生できる |
| **詰み** | tsumi | デッドロック、またはエスカレーション状態 |
| **蔵** | kura | content-addressed な成果物ストア |
| **脳** | nou | 事実から導出された信念の索引。参照専用 |

## 三つの時間軸

| コマンド | 問い | 性質 |
|---|---|---|
| `koma describe` | システムは**何であるか** | 設定・リビジョン。全値に来歴 |
| `koma now` | システムは**今なにをしているか** | 生きた調整状態。自己失効する |
| `koma brain` | システムは**何を学んだか** | 履歴・教訓。再構築可能 |

## 状態

| 語 | 意味 |
|---|---|
| **事実** | 不変・権威。蔵 + 棋譜 |
| **信念** | 導出・版付き・参照専用。脳。統合ジョブだけが書く |
| **リース** | 資源の独占権。TTL 付き。ハートビートで更新 |
| **資源** | `server:*`, `profile:*`, `store:*` など排他の単位 |
| **ドリフト** | 望ましい状態と実状態の差 |

## 可逆性クラス

自律性の上限を決める。上から順に自律度が高い。

| クラス | 意味 | 例 |
|---|---|---|
| `config` | 再読込で戻せる | Paper 設定 |
| `policy` | テーブル差し替え | 認可規則 |
| `pointer-swap` | ポインタ交換 | プラグイン版、ワールド成果物 |
| `restart` | 再起動が要る | 外部プラグイン jar |
| `irreversible` | 戻せない | データ削除、権限剥奪の連鎖 |

**`irreversible` だけが人間のゲートを通る。**

## 保証レベル

| 段 | 手段 | 何を保証するか |
|---|---|---|
| L0 | 静的解析 / 型 | 構文・依存方向 |
| L1 | 純関数 + property | ロジックの全域性 |
| L2 | MockBukkit | コマンド・権限の配線 |
| L3 | GameTest | ブロック・エンティティ挙動 |
| L4 | ボット E2E | プレイヤー視点 |
| L5 | 負荷・ファズ | 性能の相対劣化 |
| L6 | 本番観測 | 検出のみ。保証ではない |

**L4–L6 は検出であって保証ではない。**「テストで保証」と言えるのは主に L1–L2。

## エラーコード（予定）

実装より先に名前だけ決めている。コードにあるものが正で、ここは目安。

| コード | 意味 |
|---|---|
| `E_SCHEMA` | スキーマ違反 |
| `E_DUPLICATE_KEY` | JSON の重複キー |
| `E_STALE_REVISION` | 前提リビジョンが古い（TOCTOU） |
| `E_CONSTRAINT_UNSATISFIABLE` | 依存が解けない。推測せず失敗 |
| `E_HASH_MISMATCH` | 成果物のハッシュ不一致 |
| `E_NEW_CAPABILITY` | 権限・能力の追加を検出 |
| `E_NEW_EGRESS` | 新しい通信先を検出 |
| `E_NEW_EXEC` | プロセス起動・反射を検出 |
| `E_POLICY_DENIED` | 認可カーネルが拒否 |

## 使わない語

| 使わない | 理由 | 代わりに |
|---|---|---|
| 「適切に」「必要なら」 | エージェントが推測で埋める | 条件とコマンドを書く |
| `latest` | 挙動が静かに変わる | 版をピン留めする |
| 「デフォルト値」 | 省略が意味を持つ | 全域必須にする |
| 「テストで保証」 | 大半は L1–L2 | 保証レベルを明示する |
